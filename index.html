How to play

      
    
        
  1. Add gates from the palette (budgets shown per level).
    2. 
        
  2. Wire: click any pin — an output (right dot) or an input (left dots) — then click the other end. Each input takes one wire — rewiring replaces it. Click a wire to select, Del to remove.
    3. 
        
  3. Move: drag a gate. Toggle: click an INPUT. Lamps show OUTPUT (also 0/1 text).
    4. 
        
  4. Check solution runs every hidden test case. Green = pass.
    5. 
        
  5. fx: expressions shows each output as a live boolean formula — handy for checking your wiring reads the way you think.
    6. 
        
  6. Hint: Karnaugh map under the truth table regroups 2–4 input levels to help plan gates.
    7.
